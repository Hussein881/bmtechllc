# Projects

All new BMTech project work starts here.

## Categories

- `client-delivery/` — scoped work for a specific client.
- `company-platforms/` — public and operational platforms owned by BMTech.
- `internal-tools/` — reusable systems operated by BMTech.
- `experiments/` — short-lived prototypes used to validate an idea.

Each project should include a `README.md` with:

- project name and owner;
- status: proposed, active, paused, or complete;
- business problem and success measure;
- technical setup and key commands;
- data classification and access notes;
- deployment or handoff instructions.
